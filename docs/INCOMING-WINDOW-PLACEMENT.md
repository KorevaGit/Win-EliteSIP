# Перенос окна входящего вызова

Реализовано для Windows. Для будущего переноса на macOS и Linux действует то же поведение:

- Карточка перетаскивается за шапку, без принятия или отклонения вызова и без переключения фокуса из CRM.
- При включённой рандомизации каждый вызов по-прежнему получает случайное место. Перенос текущего окна не меняет этот режим и не перезаписывает фиксированную позицию. Следующее случайное смещение отсчитывается от фактического последнего места окна.
- При выключенной рандомизации или всей защите используется последнее место, выбранное оператором. Оно сохраняется сразу после переноса и переживает перезапуск. До первого переноса карточка появляется по центру экрана курсора.
- Если сохранённый монитор исчез или окно изменило размер, карточка возвращается в рабочую область ближайшего монитора. При переносе между экранами учитываются новый монитор и его DPI.
- Программное размещение и закрытие карточки позицию не сохраняют. Завершение вызова во время переноса не должно сохранять координаты уже закрытого окна.

В Windows позиция хранится в `incomingPlacement.origin` локального файла настроек в физических пикселях. Это предпочтение рабочего места, отдельное от политики защиты, профиля и управляемых полей Spark. На других платформах координаты нужно переводить в принятую там систему, сохраняя приведённые выше правила.

Шапка Windows использует невидимую область `WindowChrome.CaptionHeight`; окончание переноса определяется по `WM_ENTERSIZEMOVE`/`WM_EXITSIZEMOVE`. Кнопки приёма остаются клиентской областью, а запрет активации окна сохраняется.
