Что нового в EliteSIP 1.0.3

- Исправлено пустое окно предложения обновления в Windows 11. Версия, список изменений и кнопки снова видны. Та же правка применена к мастеру первой настройки.
- EliteSIP восстанавливает SIP после смены IP и пересоздаёт неработающий UDP-канал, даже если старый разговор ещё числится активным.
- Добавлена настройка «Поверх всех окон». Она и запуск с Windows включены по умолчанию.
- Улучшена отзывчивость: сбор сетевой диагностики идёт в фоне, таймер длительности не работает без звонков.
