# Релизный аудит dev — 19 ноября 2026

Кандидат собран из рабочей ветки dev. Номер новой версии не назначался, канал production не менялся.

| Область | Результат и остаток проверки |
| --- | --- |
| Имя приложения | В собранном Windows EXE поля FileDescription и ProductName равны EliteSIP. Имя файла, сборки и идентификаторы установщика сохранены; на вкладке «Подробности» Windows может показывать техническое имя процесса. |
| Обновление | Нужна сквозная установка поверх 1.0.3 без удаления настроек, затем перезапуск и одно подтверждение в Spark. Старая служба обновления ещё не пишет новый формат квитанции: для проверки автоматической цепочки нужны две сборки, обе с поддержкой механизма. Проверить отсрочку после перезапуска и запрет предложения при входящем и исходящем. |
| Spark | Изменения в support, коммит e3a937b. Перед сквозной проверкой требуется сервер с миграцией 0064 и новым фильтром. Проверка локальных компонентов не означает, что этот код уже развёрнут. |
| Windows 11 | Автотест системной рамки проверяет содержимое окна в обеих темах. Фактический запуск установщика и окна на Windows 11 нужен для пилота. |
| Звонки и сеть | Лаборатория подтверждает восстановление после смены IP и работу с синтетическим допуском. Проверить кандидата на офисном и удалённом месте: входящий, исходящий, перевод, завершение, история, обрыв связи. Офисный стенд не заменяет VPN и реальный шлюз. |
| Аудио | Проверены совпадение отсчётов и восстановление вывода Realtek. Изменения буферов и счётчиков в dev следует проверить в составе кандидата на USB/Bluetooth, с речью в обе стороны. Дальнейшую оптимизацию отложили; незавершённая ETW-серия не считается подтверждением ускорения. |

Перед публикацией: собрать версионированный установщик, проверить подписанный манифест и SHA-256, провести пилот Win10/11 и сквозную проверку Spark. Сборка для этого аудита — папка artifacts/release-audit, не установщик.
