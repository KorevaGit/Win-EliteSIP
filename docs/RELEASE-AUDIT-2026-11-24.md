## Известные ограничения

- Выключенный микрофон пишет громкость 0 в настройки. После перезапуска с выключенным микрофоном включение вернёт 100 %, а не прежнее значение: оно хранится только в памяти окна.
- При автоуровне микрофона ползунок недоступен и в ноль не уходит; о выключении говорит только красный заголовок.
- Квитанция восстановления живёт сутки: машина, которую Spark знает, при открытом окне шлёт заявку раз в сутки и получает 202. Нагрузка — один запрос.
- «Поверх всех окон» теперь поднимает и настройки, журнал, «Управление»; по умолчанию включено.
- Ревизия настроек 5 на Windows и Linux означает разное; файлы настроек между системами не переносятся.
